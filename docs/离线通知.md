# 电话卡离线通知

打开“电话卡”→对应卡片“设置”，在“离线通知”中选择一个已启用的通知通道，并填写离线小时数，默认 1 小时。选择“不启用”即关闭该卡的离线通知。通知通道在“转发设置”中创建，可以使用邮件、Bark、PushDeer 或 Quicker；不必同时绑定为该卡的短信转发通道。

平台根据设备最后一次成功上报或轮询的时间判断离线。设备从未连接过平台时不发送离线通知。超过阈值后，后台约每 30 秒检查一次，同一次离线只发送一次；设备恢复连接后，下一次离线重新计时。通知发送失败会按退避间隔重试，直至发送成功或设备恢复。短信关键词和正则截取规则不影响离线通知。

这项功能需要 `V6__device_offline_notifications.sql` 迁移。Docker 容器或 FastAPI 启动时自动运行迁移，不需要手工执行 `python -m app.migrate`。更新应用时保留原 PostgreSQL、`.env`、端口和代理配置，设备固件及 API Key 无需改变。已有电话卡默认关闭离线通知，需要逐张卡选择通道。
